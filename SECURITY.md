# Security policy

## Scope

This project is currently a research and development effort. There is not yet a released modern macOS driver or installer.

Security reports are still welcome, especially if they concern code in this repository, future driver designs, installation procedures or handling of connected hardware.

## Reporting a vulnerability

Please do not publish passwords, private data, exploitable details or a working exploit in a public issue.

If GitHub's **Report a vulnerability** option is available in this repository's Security tab, use it to submit a private report.

If private vulnerability reporting is not available, open a public issue containing only a brief note that you have a security concern and would like a private contact route. Do not include exploit details in that issue.

## What to include

Where safe to do so, include:

- The affected file, component or planned feature.
- The operating system and version.
- The potential impact.
- Steps to reproduce, shared privately.
- Any suggested mitigation.

Please allow time for the report to be reviewed before publicly disclosing details.

## Current support status

There are no released driver builds for which security fixes or a response-time guarantee can be promised. This policy will be updated as the project matures.
